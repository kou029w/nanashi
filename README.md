# Nanashi

Nanashi makes random email aliases for Bitwarden through a SimpleLogin-compatible API. It appends each alias to `/etc/aliases`, which maddy reads as an alias table.

## Usage

Print one random address and exit:

```sh
NANASHI_DOMAIN=mail.example ./nanashi
```

```
yvbszapm@mail.example
```

Run the API:

```sh
NANASHI_KEY=... NANASHI_DOMAIN=mail.example NANASHI_TO=me@mail.example ./nanashi --listen 127.0.0.1:8080
```

| Variable          | Meaning                                         | Default        |
| ----------------- | ----------------------------------------------- | -------------- |
| `NANASHI_DOMAIN`  | Domain of the aliases                           | required       |
| `NANASHI_KEY`     | API key                                         | required (API) |
| `NANASHI_TO`      | Address the aliases forward to                  | required (API) |
| `NANASHI_ALIASES` | File to append to. Nanashi needs write access.  | `/etc/aliases` |

The container image runs as UID 65532 and needs the same arguments. Mount the host file and let that UID write it:

```sh
docker run -p 8080:8080 -v /etc/aliases:/etc/aliases -e NANASHI_KEY=... -e NANASHI_DOMAIN=mail.example -e NANASHI_TO=me@mail.example fogtype/nanashi --listen :8080
```

Test it:

```sh
curl -i -X POST 'http://127.0.0.1:8080/api/alias/random/new?hostname=shop.example' \
  -H "authentication: $NANASHI_KEY" \
  -H 'content-type: application/json' \
  -d '{"note":"Website: shop.example. Generated by Bitwarden."}'
```

```
HTTP/1.1 201 Created
Content-Type: application/json

{"alias":"o32fo2mn@mail.example","email":"o32fo2mn@mail.example"}
```

A wrong key gets `401` and `{"error":"Wrong api key"}`. `/etc/aliases` gets two new lines:

```
# 2026-10-31T21:37:47+09:00 Website: shop.example. Generated by Bitwarden.
o32fo2mn@mail.example: me@mail.example
```

## maddy

Add the file to `table.chain`:

```
optional_step file /etc/aliases
```

## Bitwarden

Pick SimpleLogin as the service. Set Server URL to the public URL of the API and the API key to `NANASHI_KEY`.
